The mark at every size

The full wordmark doesn't survive 16px, so the favicon distills it to the essentials: a lowercase "a" in navy and the gold square dot. Continuity with the wordmark is preserved; the brand reads as the brand at every scale.

03 · iOS home screen

apple-touch-icon in context

When users add nap to their iOS home screen as a PWA, this is the icon. iOS masks icons with a rounded rectangle — we use an off-white background rather than navy so the mark reads cleanly against any wallpaper.

The design call. Finance apps on iOS home screens tend toward navy-on-white rather than white-on-navy — it reads as professional and trustworthy rather than consumer-y. Our choice mirrors brands like Mercury, Ramp, and Brex.

Why off-white, not pure white. Pure white app icons read as clinical and slightly aggressive against iOS's soft system wallpapers. The warm off-white (#FAFAF7) matches the product's page background for system coherence.

iOS masking. The icon is saved as a straight PNG with our own rounded corners baked in at 22% radius. iOS will apply its own mask on top — our corners match iOS's native radius closely enough that there's no visible double-rounding.

05 · Files and usage

The deliverable set

A complete favicon set covers every modern platform. The SVG is preferred by recent browsers; PNGs are fallbacks; apple-touch-icon and android-chrome cover mobile home-screen install.

HTML snippet for the site head

Drop this into the <head> of every page. Modern browsers pick the best format; older browsers fall back automatically.

<!-- Primary: SVG for modern browsers --> <link rel="icon" type="image/svg+xml" href="/favicon.svg" /> <!-- PNG fallbacks for older browsers --> <link rel="icon" type="image/png" sizes="32x32" href="/favicon-32.png" /> <link rel="icon" type="image/png" sizes="16x16" href="/favicon-16.png" /> <!-- iOS home screen --> <link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png" /> <!-- Android / PWA via manifest --> <link rel="manifest" href="/site.webmanifest" /> <!-- Theme color matches brand navy --> <meta name="theme-color" content="#2F3E52" />
