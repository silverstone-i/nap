The real test for semantic colors isn't the swatch — it's how they read as status indicators at glance speed. Warning orange and error red separate clearly here; you can tell at a glance which is which without reading the label.

Accessibility note
Color alone never conveys status. Every badge has a distinctive shape; every alert has an icon and text label. The system survives deuteranopia (6% of men), protanopia (2%), tritanopia (rare), and full achromatopsia. If a status indicator is ever designed with color as the sole cue, it violates this system.
Icon vocabulary · semantic states

Each semantic state has exactly one icon glyph used consistently across alerts, field errors, toasts, and any future indicator. Badges use larger-scale shapes (triangle, circle, diamond) because the tiny circular glyphs don't read at badge size — but the meaning is paired across both scales.

State Alert glyph Badge shape Meaning
Success ✓ ✓ Completed, confirmed, approved
Warning ! ▲ Attention required, review before proceeding
Error × ● Blocked, rejected, cannot proceed
Info i i Informational, in progress, neutral update
Neutral / draft — ◇ Not yet acted on, saved but unsubmitted

Why ✓ ! × i and not free-form: These four glyphs carry 40+ years of design system heritage — Apple, Microsoft, GNOME, KDE, every modern OS. Users recognize them pre-consciously. Using different glyphs for the same meaning (a ! for error, a ⚠ for warning) costs comprehension without gaining anything.

03 · Gold discipline

The four approved uses

Gold appears in exactly these four places across the entire product and marketing surface. Nowhere else. Not in chips, badges, focus rings, icons, or decoration. This restraint is what makes the gold feel premium instead of loud.

RULE
If a user sees more than three gold elements on any single screen, something is wrong. The palette works because gold is rare. Break the rule and the discipline collapses.

04 · Components

Buttons, navigation, menus

The system applied to the elements users see most often. One rule across all of it: count the gold on any screen — logo dot, max one primary CTA stripe, max one active nav indicator, plus final-total accent in reports. Never more.

Three-button hierarchy
primary · secondary · tertiary
One primary per screen. Primary carries the gold stripe. Secondary is the common alternative, quiet by design. Tertiary is for escape hatches. The user always knows which action you expect them to take.
Primary button · all states
default · hover · disabled
Gold stripe expands from 2px to 3px on hover; padding shifts 1px to keep label visually anchored. Disabled state drops the stripe entirely — accent never appears on inactive elements.
Destructive actions
tertiary · danger
For confirmed destructive actions, primary stays navy — don't swap Cancel into primary to be polite. For inline destructive actions in tables or forms, use the danger-tinted tertiary variant.

Every invoice, journal entry, vendor record, and project budget passes through a form. Restraint here means no gold on focus states (dozens of inputs per screen would overwhelm), monospace-right-aligned for numeric entry, and parentheses for negative values because that's the accounting standard.

Voice principles

The rules that keep marketing copy sounding like one brand, not five.

01
Confident, never clever
State things plainly. No puns beyond what the name already does. The product is serious finance software; the writing reflects that.
02
Specific, never generic
"Project-first accounting" beats "modern ERP." "Construction, manufacturing, services" beats "businesses." Vague language signals a vague product.
03
Anti-bloat, not anti-competitor
"Not another program" is about category fatigue, not naming rivals. Never trash SAP, NetSuite, or QuickBooks by name — that makes us look small.
04
Short over long
If a sentence can be three words instead of ten, it should be three. CFOs scan, they don't read. Earn their time.
05
Nouns over adjectives
"The ledger that thinks in projects" beats "Our revolutionary AI-powered accounting platform." Verbs and nouns carry weight; adjectives leak credibility.
Use
project-first · real-time · profitability · cashflow · truth · ledger · post · close · reconcile · approve · track · module · tenant · workspace · workflow
Avoid
synergy · leverage · solution · game-changing · revolutionary · next-gen · paradigm · unlock · empower · disrupt · seamless · robust · cutting-edge

Product vs. marketing scales
Marketing type is bigger, looser, and more generous than product type by design. Inside the app, a user is scanning for a specific invoice among hundreds at 14px body and 12px labels. On the landing page, a prospect is being persuaded at 64px hero and 20px lede. Same brand, same font family, different scale rhythm. Don't mix them — a product screen with marketing-scale typography looks amateur; a marketing page with product-scale typography looks cramped.
09 · Discipline checklist

What this system is and isn't

Do
  • Let navy carry the weight — 70–80% of visual surface
  • Use gold only in the four approved places
  • Pair display type with JetBrains Mono for numbers
  • Use warm off-white for page backgrounds, pure white for cards
  • Keep buttons quiet — only one CTA per screen gets the gold stripe
  • Use Inter Medium for the wordmark, never Bold
  • Stack form labels above inputs, not to the left
  • Use parentheses for negative values — the accounting standard
  • Mark required fields with a neutral-gray asterisk — color is reserved for validation states, not markers
  • Every status indicator has a shape, not just a color
  • Monospace numerics in tables — decimals must align vertically
  • Use skeleton rows for loading tables, not spinners
  • Lead with "TBD" on sales surfaces
  • Use "Sleep on your books." in brand moments — footer, About page, swag
  • Match type scale to context — marketing is bigger, product is denser
Don't
  • Add gold to chips, badges, icons, focus rings, or borders
  • Put gold on form focus states — dozens of inputs would overwhelm
  • Use gradients in the wordmark or gold color
  • Return to script or handwriting fonts (no Allura)
  • Reintroduce the cloud glyph
  • Use pure white as the page background
  • Flood CTA buttons with gold fill — always keep navy as the base
  • Use bold weight wordmarks — reads aggressive
  • Nest boxed sections within boxed sections in forms
  • Use red for destructive button fills — navy + clear labeling is safer
  • Zebra-stripe table rows — single-pixel borders do the job better
  • Add vertical gridlines in tables — horizontal rhythm is enough
  • Mix the two taglines — never use both on the same surface
  • Use product-scale typography on marketing pages — reads cramped
  • Use corporate buzzwords — "synergy," "disrupt," "seamless," "robust"
