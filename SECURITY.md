# Security Policy

## Supported versions

NAP is pre-release. Only the current `main` branch receives security fixes.

## Reporting a vulnerability

**Do not open a public issue for a vulnerability.**

Report it privately via [GitHub security advisories](https://github.com/silverstone-i/nap/security/advisories/new) or by email to <ian@isilverstone.com>.

You will get an acknowledgment, and a fix will be coordinated before public disclosure. Please include enough detail to reproduce the issue — affected component, steps, and impact.

See [COLLABORATION.md](COLLABORATION.md) for the full contribution and disclosure context.
